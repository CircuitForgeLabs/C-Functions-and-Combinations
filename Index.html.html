By Engr. Lee-Mher Binay-an

Functions let you package reusable logic. The combination (nCr) formula gives that logic something concrete to compute. Conditional statements and C++'s math library make the whole thing robust. Work through all three lessons, check your understanding, then build the lab.

function Lesson 1 — C++ Functions

▶1.1 What is a function?

A function is a named, reusable block of code that performs a specific task. Write the logic once, call it whenever you need it — shorter, more readable, easier-to-fix programs.

▶1.2 Declaration and definition 
// Function prototype (declaration)
int add(int a, int b);

// Function definition
int add(int a, int b) {
    return a + b;
}
▶1.3 Calling a function 
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int sum = add(5, 3);
    cout << "Sum: " << sum << endl;
    return 0;
}
▶1.4 Void functions

A void function performs an action without returning a value.

void greet(string name) {
    cout << "Hello, " << name << "!" << endl;
}
▶1.5 Pass by value vs. by reference 
void addOne(int x) {        // pass by value
    x = x + 1;               // only changes the local copy
}

void addOneRef(int &x) {    // pass by reference
    x = x + 1;               // changes the original variable
}
▶1.6 Default arguments 
double power(double base, int exponent = 2) {
    double result = 1;
    for (int i = 0; i < exponent; i++) result *= base;
    return result;
}

power(5);       // uses default exponent = 2 → 25
power(2, 3);    // → 8
▶1.7 Function overloading 
int square(int n) { return n * n; }
double square(double n) { return n * n; }
Key pointA function's signature is its name plus parameter types. Overloaded functions must differ in signature — return type alone isn't enough.
▶1.8 Lesson summary
  • Functions package reusable logic; can return a value or be void
  • Arguments pass by value (copy) or by reference (original)
  • Default arguments and overloading add flexibility

nCr Lesson 2 — C++ Combinations

▶2.1 The combination formula

A combination counts how many ways to choose r items from n, where order doesn't matter: nCr = n! / (r!(n−r)!). This lesson uses that formula as a hands-on exercise in writing and reusing functions.

▶2.2 Step 1 — a factorial function 
long long factorial(int n) {
    long long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
Key point0! and 1! both equal 1 — when n is 0 or 1, the loop body never runs, so result stays 1.
▶2.3 Step 2 — the combination function

combination() calls factorial() three times — one function reusing another.

long long combination(int n, int r) {
    return factorial(n) / (factorial(r) * factorial(n - r));
}
▶2.4 Step 3 — put it together 
#include <iostream>
using namespace std;

long long factorial(int n) {
    long long result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}

long long combination(int n, int r) {
    return factorial(n) / (factorial(r) * factorial(n - r));
}

int main() {
    int n = 5, r = 2;
    cout << n << "C" << r << " = " << combination(n, r) << endl;
    return 0;
}

Output: 5C2 = 10 — 10 ways to choose 2 items out of 5.

▶2.5 Lesson summary
  • nCr counts ways to choose r items from n, order doesn't matter
  • Splitting out factorial() first keeps combination() short and readable
  • A practical example of one function calling another

if / switch Lesson 3 — Conditionals & Math

▶3.1–3.2 if, if-else, else if 
if (r > n) {
    cout << "r cannot be greater than n." << endl;
} else if (r < 0 || n < 0) {
    cout << "n and r must not be negative." << endl;

    cout << "Valid input." << endl;
}

▶3.6 Validating combination input

Conditionals catch bad input before it reaches your calculation — here, before calling combination() from Lesson 2.

if (n < 0 || r < 0) {
    cout << "n and r must not be negative." << endl;
} else if (r > n) {
    cout << "r cannot be greater than n." << endl;
} else {
    cout << n << "C" << r << " = " << combination(n, r) << endl;
}
▶3.7 Lesson summary
  • if / else if / switch branch a program based on conditions
  • Relational & logical operators build the conditions
  • <cmath> supplies pow(), sqrt(), abs(), and more
  • Validating input prevents incorrect or crashing results
